# Agent Sandbox

system dashboard, keyboard controls, and ESP32 Bluetooth diagnostics.

See [setup and usage](codex/README.md), [progress](codex/PROGRESS.md),
and [outstanding work](codex/TODO.md).

and agent configuration are excluded from version control.
